# Inventory Management System Frontend

The frontend uses React, Vite, React Router, Tailwind CSS, and Axios. For full-stack setup and API documentation, see the repository [README](../README.md).

## Setup

Install dependencies and configure `frontend/.env` with the backend origin. Do not include `/api` in the value:

```env
VITE_API_URL=http://localhost:4000
```

Start the development server with `npm run dev`. Run `npm run lint` for ESLint and `npm run build` for a production build.
